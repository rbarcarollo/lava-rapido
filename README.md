# Lava-Rápido

Aplicativo Flutter para controle de lavagens de um lava-rápido, adaptado a partir do Projeto Bank estudado em aula. Os dados são mantidos apenas em memória (sem persistência).

## Funcionalidades

- Lista de lavagens registradas (`ListView.builder`, `Card`, `ListTile`).
- Formulário para registrar uma nova lavagem (número da vaga e valor do serviço).
- Valores monetários formatados no padrão brasileiro (`NumberFormat`).
